Python solutions for four introductory programming problems. Each program reads from standard input and prints its answer to standard output.

## How to run

Run a program from the repository root and type the input shown in its test file:

```bash
python problems/p1_reverse_words.py
python problems/p2_binary_search.py
python problems/p3_digit_sum.py
python problems/p4_pair_count.py
```

Sample inputs and expected outputs are in the `tests/` folder. You can also run a sample with input redirection, for example:

```bash
python3 problems/p2_binary_search.py < tests/p2_input.txt
```

## Problems

1. Reverse the order of words in the input line.
2. Search a sorted list with a manually implemented binary search and print the zero-based index or `-1`.
3. Find the sum of an integer's digits using recursion.
4. Pair-count interpretation used here: for `n`, target `k`, and `n` integers, count index pairs `i < j` whose values sum to `k`. The original prompt ended after “count pairs i”; please confirm this interpretation.
